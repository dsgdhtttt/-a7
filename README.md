# 旧物回收项目全套开源系统

源码地址：ym7k.com/20061/

随着资源回收理念普及，传统旧物回收模式存在下单不便、品类杂乱、称重对账麻烦、回收台账缺失等痛点。这套旧物回收全套开源系统围绕用户下单、回收调度、品类计价、上门收运、仓库入库、财务结算、数据统计搭建完整业务闭环，支持私有化部署，适合回收站点、再生资源服务商、社区回收企业搭建线上回收服务平台。

用户端线上预约是系统的入口功能。居民可以在前端选择需要回收的物品品类，比如废纸、塑料、金属、家电、旧衣物等，填写回收数量、预估重量，选择上门回收的时间与地址，提交预约订单。用户也可以选择自行送到回收站点。订单提交成功后，系统自动推送通知给回收人员，同时用户能够随时查看订单状态，跟踪接单、上门、完成进度，减少电话沟通成本。

品类管理与计价模块，规范回收定价。管理员可以在后台维护所有回收品类，对不同品类单独设置回收单价，区分不同规格、成色的计价标准，价格可随时调整。系统支持按重量计费，回收员上门现场称重后录入实际重量，自动核算应付金额，避免人工口算出错。针对大家电、家具等大件物品，还可以设置上门服务费，计价规则透明清晰，让居民清楚回收款项明细。

回收派单与外勤调度是业务核心。平台配备调度中心，所有预约订单统一汇总展示。管理员可以根据回收员位置、服务片区进行派单，回收人员接收订单后按路线上门。回收员移动端可查看客户地址、回收物品备注，完成称重、拍照留存、确认结算。订单状态实时更新，分为待接单、上门中、已回收、已结算等，调度人员能够实时监控所有外勤任务，合理规划路线，提升回收效率。

仓库入库与库存台账，管控回收物资流转。回收员上门收回的物资运回站点后，仓管人员办理入库，录入品类、重量、入库时间，生成入库记录。系统实时统计仓库各类物资存量，当某类物资积攒到一定量后，可发起外销出库单，记录出货品类、重量、收购商信息和外销收入。每一批物资从上门回收、入库到外销出库全程留痕，形成物资流转链条，防止物资流失，方便盘点。

资金结算与订单对账模块理清收支。系统记录每一笔给居民的回收付款，以及物资外销产生的收入，自动生成资金流水。后台支持按时间段、回收员、品类筛选订单，导出对账报表。回收员业绩自动统计，可用来核算提成工资，清晰展示个人接单量、回收总重量、创造营收，解决回收行业人员业绩核算难的问题。

后台审核、权限与运营拓展功能保障平台稳定运行。系统划分调度员、回收员、仓管、财务、超级管理员等角色，权限相互隔离。回收员仅处理分配给自己的订单，财务只查看对账和资金数据。后台数据看板汇总订单总量、各类物资回收量、营收数据、活跃用户，直观反映业务情况。系统预留扩展接口，后续可以增加回收积分兑换、智能回收柜联动、企业批量回收、公益旧衣捐赠等功能。

整套旧物回收系统不只是预约下单工具，融合线上报单、智能派单、现场计价、物资出入库、业绩核算、财务对账于一体。私有化部署可以自主掌握订单、客户和物资数据，摆脱第三方平台约束，助力再生资源回收企业、社区回收网点实现标准化、数字化运营，是绿色回收业务线上化落地的优质方案。
